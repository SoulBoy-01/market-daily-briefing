# ADR 0002：哈希已发布报告文件

- 状态：已接受
- 日期：2026-07-29

## 背景

原始快照已有 SHA-256，发布记录和事实在 SQLite 中采用追加式约束，但发布后的 Markdown 与 HTML 文件仍可能在数据库之外被修改。仅检查文件存在不能证明访问或恢复时看到的文件仍是发布时版本。

## 决策

1. 发布时分别计算并持久化 Markdown 与 HTML 的 SHA-256。
2. 正常访问、完整性检查和恢复流程必须验证对应文件哈希。
3. 哈希缺失或不符视为审计损坏，阻断正常展示；系统不得自动重建或覆盖已发布文件。
4. 本轮不为 SQLite 事实账本定义规范化序列化格式或清单哈希。

## 后果

- 发布协议和兼容迁移需要新增报告文件哈希字段及旧记录处理规则。
- 报告文件可以被独立验证，且不会扩大为整个账本的密码学证明协议。
- 若未来需要跨机器导出和验证事实账本，应另立决策定义规范化格式。
