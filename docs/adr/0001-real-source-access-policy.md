# ADR 0001：真实来源访问与零预算准入策略

- 状态：已接受
- 日期：2026-07-28

## 背景

阶段三需要为上证指数、深证成指和创业板指提供两个相互独立的实际数据来源，同时保持本地、非商业、单维护者的学习项目定位。来源许可、访问稳定性、自动化程度和成本之间存在真实取舍。

## 决策

1. 允许使用需要免费注册或 API Key、且条款清晰的数据服务。凭证只能通过环境变量注入，不写入仓库、快照或报告。
2. 核心指数双来源固定为一个对应交易所的官方来源，加一个独立的已批准 API 服务。AkShare 等工具不计为实际数据提供方。
3. 官方来源可以通过公开页面或数据端点自动读取，但启用前必须核验服务条款与访问规则，并实施低频访问、原始证据保存和结构变化检测。
4. 自动来源临时不可用时，允许维护者人工导入官方证据。人工导入必须经过同一暂存、哈希、双来源核对和发布门禁。
5. 当前真实来源预算为零。许可不清晰或需要付费才能满足使用条件的来源不得启用。找不到合规免费核验来源时，真实模式保持禁用。

## 后果

- 来源登记和许可状态是启用真实模式的硬门槛。
- 零预算可能推迟阶段三真实运行，但不能通过单来源发布、许可推测或未登记抓取换取进度。
- 具体免费核验提供方仍需单独调研和由所有者批准；本 ADR 不批准任何具体服务。
- fixture、mock 和黄金评测路径不受影响。
