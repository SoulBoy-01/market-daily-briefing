# ADR 0004：真实模式必须通过真实来源黄金案例

- 状态：已接受
- 日期：2026-07-29

## 背景

阶段二已有 10 日黄金评测骨架和 mock 数据，可以验证核对器、门禁与失败路径的离线契约，但不能证明未来真实来源的字段解析、交易日、数值、分类和覆盖判断正确。将“验证版”作为界面标签不能替代真实证据。

## 决策

1. 真实模式启用前，必须建立 10 个真实来源黄金案例。
2. 每个案例包含许可允许保存的原始响应、人工确认的期望结果、来源登记引用和覆盖说明。
3. 10 个案例必须全部通过核心数值准确性、交易日和来源匹配、分类、硬门禁、覆盖缺口可见性及哈希完整性指标。
4. 现有 mock 黄金集继续用于验证软件契约，但不计入真实模式解锁证据。
5. 若来源条款不允许保存构成案例所需的响应，该来源不能用于解锁真实模式。

## 后果

- 单次真实网络冒烟或“实验性”标签不能单独解锁真实运行。
- 来源选择、许可登记和黄金案例建设形成真实适配器启用前的阻塞关系。
- 在阻塞解除前，可以继续开发和测试不访问网络的配置、审计与编排契约，但正常 Web 界面不得开放真实运行。
