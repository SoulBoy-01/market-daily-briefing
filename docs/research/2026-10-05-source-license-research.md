## 一、调研问题与判定标准

判定标准全部来自 ADR 0001《真实来源访问与零预算准入策略》与 ADR 0004《真实模式必须通过真实来源黄金案例》：

| 编号 | 标准 | 出处 |
| --- | --- | --- |
| S1 | 需要免费注册或 API Key 的服务允许使用，但**条款必须清晰**；凭证只能经环境变量注入 | ADR 0001 决策 1 |
| S2 | 双来源 = 一个**对应交易所的官方来源** + 一个**独立的已批准 API 服务**；AkShare 等聚合 SDK 不计为实际数据提供方 | ADR 0001 决策 2 |
| S3 | 官方来源可经公开页面或数据端点自动读取，启用前必须核验服务条款与访问规则，并实施低频访问、原始证据保存、结构变化检测 | ADR 0001 决策 3 |
| S4 | 零预算：**许可不清晰**或**需要付费才能满足使用条件**的来源不得启用；找不到合规免费核验来源时真实模式保持禁用 | ADR 0001 决策 5 |
| S5 | 黄金案例必须包含**许可允许保存的原始响应**；来源条款不允许保存构成案例所需响应的，该来源不能用于解锁真实模式 | ADR 0004 决策 2、5 |

核心指数：上证指数 000001.SH、深证成指 399001.SZ、创业板指 399006.SZ，需要收盘点位与涨跌幅。本地、非商业、单维护者用途。

每项候选按以下维度判定：

- **保存响应**：条款是否允许把原始 HTTP 响应作为审计快照 / 黄金案例保存（S5）
- **再展示**：条款是否允许把解析后的指数数据放进简报并经审查界面呈现（本地、非商业）
- **程序化访问**：条款 / robots / 接口限制对自动化读取的规定（S3）

## 二、候选逐项判定

### 2.1 上交所官网（www.sse.com.cn）

**提供方身份**：上海证券交易所（行情数据知识产权方含其运营的上证所信息网络有限公司）。

**访问方式**：官网「行情走势」页 https://www.sse.com.cn/market/price/trends/ 展示上证系列指数；页面 JS 声明行情数据后端 `sseQueryURL = "//query.sse.com.cn/"`（http 协议下为 `yunhq.sse.com.cn`）。实测 `query.sse.com.cn/commonQuery.do` 免登录可返回 JSON（需携带 `Referer: https://www.sse.com.cn/...`）；确切的 sqlId 与参数需在适配器实现阶段从页面脚本确认。

**访问规则核验**：`https://www.sse.com.cn/robots.txt` 返回 404（无 robots 声明）；`query.sse.com.cn/robots.txt` 同样 404。

**条款**：法律声明 https://www.sse.com.cn/home/legal/ ，关键原文：

> 三、在遵守中国有关法律与本声明的前提下，任何机构或者个人可基于**非商业目的浏览、下载**本网站的内容。未经上海证券交易所书面许可，任何机构或者个人不得**以向他人出售牟利为目的**，使用本网站的任何内容，此种使用包括但不限于拷贝、下载、存贮、通过硬拷贝或电子抓取系统获取、发送、转换、出租、演示、转载、复制、修改、销售、传播、出版或任何其它形式的散发。

> 五、……并不对其准确性、完整性和及时性做出任何保证。……上海证券交易所和上证所信息网络有限公司不承担任何法律责任。

**判定**：

| 维度 | 判定 | 依据 |
| --- | --- | --- |
| 保存响应 | 有条件允许 | 第三条第一句明确允许非商业目的浏览、下载；「存贮、电子抓取」列于「以向他人出售牟利为目的」的使用枚举内，按语法不约束非牟利用途，但存在解释空间（见开放问题 1） |
| 再展示 | 允许（本地、非商业） | 同上；第三条未对非商业再展示设禁 |
| 程序化访问 | 未明文授权亦未明文禁止 | 无 robots.txt；法律声明只约束「使用内容」的目的与方式，未单列自动化访问规则。低频访问需自行约定并登记（S3） |

**结论：待定（有条件符合）**。
- 符合：S2 之「对应交易所的官方来源」（上证指数 000001.SH 为上交所官方指数）；S3（公开页面/端点可自动读取，条款可核验）；S1（无需注册、零预算）。
- 缺失 / 风险：法律声明对「存贮、电子抓取」的措辞存在解释空间，需所有者批准解释后才可登记启用；不允许用于深证成指 / 创业板指（非上交所指数）。

### 2.2 深交所官网（www.szse.cn）

**提供方身份**：深圳证券交易所。

**访问方式**：官网「深市指数」页 https://www.szse.cn/market/exponent/pandect/index.html 与「行情信息」页 https://www.szse.cn/market/trend/index.html（页面确认展示深证成指、创业板指）。数据经公开 JSON 接口 `https://www.szse.cn/api/report/ShowReport/data?SHOWTYPE=JSON&CATALOGID=<目录>&TABKEY=<页签>` 加载；实测该接口免登录可访问（带官网 Referer，返回 JSON 元数据）。指数行情对应的 CATALOGID 需在适配器阶段确认。

**访问规则核验**：`https://www.szse.cn/robots.txt` 返回 HTTP 200 但内容为 0 字节——即未声明任何抓取限制，也未授权。

**条款**：法律声明 http://www.szse.cn/application/laws/index.html （页脚「法律声明」），关键原文与上交所几乎同构：

> 三、在遵守中国有关法律与本声明的前提下，任何机构或者个人可基于**非商业目的浏览、下载**本网站的内容。未经深圳证券交易所书面许可，任何机构或者个人不得**以向他人出售牟利为目的**，使用本网站的任何内容，此种使用包括但不限于拷贝、下载、存贮、通过硬拷贝或电子抓取系统、发送、转换、出租、演示、转载、复制、修改、销售、传播、出版或任何其它形式的散发。

> 五、……并不对其准确性和完整性做出任何保证。……深圳证券交易所无须承担任何法律责任。

**判定**：

| 维度 | 判定 | 依据 |
| --- | --- | --- |
| 保存响应 | 有条件允许 | 同上交所：非商业浏览/下载在允许侧；「存贮、电子抓取」的解释空间同上 |
| 再展示 | 允许（本地、非商业） | 同上 |
| 程序化访问 | 未明文授权亦未明文禁止 | robots 为空；无自动化访问的成文规则。低频访问需自行约定并登记（S3） |

**结论：待定（有条件符合）**。
- 符合：S2 官方来源（深证成指 399001.SZ、创业板指 399006.SZ 为深交所官方指数）；S3；S1。
- 缺失 / 风险：与上交所相同的条款解释空间；不覆盖上证指数。

### 2.3 Tushare（tushare.pro）

**提供方身份**：北京沃远数据科技有限公司。用户协议定义其服务为「基于公开信息整理加工各类经济和行业数据」——即交易所公开数据的**聚合加工方（二级代理）**，非交易所官方；站内查无任何交易所信息网络授权分发的公开声明。

**访问方式**：注册账号 + 个人 Token（HTTP / Python SDK），符合「凭证经环境变量注入」的要求。

**免费门槛（零预算核心问题）**：积分门槛表 https://tushare.pro/document/1?doc_id=108 ：

> 指数日线行情 index_daily　全部历史，交易日15点～17点更新　**2000起**

积分获取办法 https://tushare.pro/document/1?doc_id=13 ：注册送 100 分、完善资料 +20 分、推荐注册 +50 分；高级权限主要靠「付费 200（高级用户QQ群）」或「赞助 Tushare 社区获得积分权限，金额随意……对我们的支持越大，开放的权限越多」。平台对高校学生 / 教师另有免费 2000 / 5000 分通道（数据服务协议第一节第 3 条）。

**条款**：

- 用户协议 https://tushare.pro/document/1?doc_id=409
- 数据服务协议 https://tushare.pro/document/1?doc_id=405 ，关键原文：

> 5. 本服务是在您遵守本协议及相关法律、法规、政策、公序良俗等的前提下，Tushare给予您一项**个人的、不可转让的、非商业用途的、可撤销的、有期限及非排他性的许可**。您须遵守各项法律、法规及与Tushare达成的各项协议，**仅可为非商业目的使用，并仅可用作个人查看使用**。

> （免责条款）1. ……Tushare均不能保证其数据的及时性、准确性和完备性。所有数据及内容仅供参考，不构成投资建议……

**判定**：

| 维度 | 判定 | 依据 |
| --- | --- | --- |
| 保存响应 | 未获许可 | 「仅可用作个人查看使用」未授予留存副本的权利；平台文档虽教授「数据存入 MySQL / Mongo」（踩坑记录栏目），但属技术教程，不构成许可 |
| 再展示 | 未获许可 | 同上，「个人查看」未覆盖经界面再展示 |
| 程序化访问 | 允许（经官方 API + Token） | 官方接口即设计为程序调用，频次受积分约束 |

**结论：不符合**。
- 违反 S4：指数日线 index_daily 需 2000 分，免费注册路径（120 分封顶，不考虑逐个拉人头）不可达，**需要付费才能满足使用条件**（除非所有者具备高校师生身份，见开放问题 3）。
- 违反 S5：即便拿到权限，「仅可用作个人查看使用」与黄金案例「许可允许保存的原始响应」相抵触。

### 2.4 BaoStock（baostock.com）

**提供方身份 / 现状**：站点已改版为「Baostock 交易技术商城」，运营方为**阿尔法联合（上海）软件技术有限公司**（见其隐私政策与作者签约协议主体条款），带注册、登录、积分与支付（平台交易规则：创作者分成 80%，平台服务费 20%）。Python 包 `baostock` 0.9.4 仍于 2026-09-21 更新（PyPI，仅依赖 pandas）。旧版维基（Internet Archive 存档）自述「免费、开源的证券数据平台（无需注册）」，但该承诺未出现在现行条款体系中。

**访问方式**：Python SDK，`bs.login()` 历史上免 token 匿名登录；新网站要求注册才能使用商城功能。**注意：新版条款未再书面确认数据 API 免费无 token 的状态。**

**条款**：站点有书面条款，经 `/articleMall/api/contract` 接口下发（路由 /terms、/privacy、/agreement、/disclaimer）：

- 用户服务协议（contract_type=1）：面向商城 Web 产品的通用协议
- 作者签约协议（type=2）、平台交易规则（type=4）：面向商城创作者交易
- 隐私政策（type=3）：主体为阿尔法联合（上海）软件技术有限公司
- 免责声明（type=5），关键原文：

> 5. 知识产权　- 网站内容（包括文字、图片、代码、设计等）版权归我们所有，**未经书面许可不得复制、传播或用于商业用途**。

> 1. 网站内容责任　- 本网站提供的信息仅供参考，不构成任何形式的投资、法律或专业建议……

**数据来源**：现行条款**没有任何一条**说明行情数据从何而来、是否授权再分发（旧版维基同样未见明示数据来源）。

**判定**：

| 维度 | 判定 | 依据 |
| --- | --- | --- |
| 保存响应 | 条款不清晰 | 现行条款全部针对商城 / 社区内容；免责声明第 5 条的复制禁令字面覆盖「网站内容」，未界定数据 API 响应是否在内；无任何授权存储的明文 |
| 再展示 | 条款不清晰 | 同上 |
| 程序化访问 | 条款不清晰 | 无条款提及 Python 数据接口的自动化使用；免费 / 无 token 现状未在现行条款中确认 |

**结论：待定（条款不清晰，按 S4 不得启用）**。
- 有利项：零预算、历史上免注册、指数数据（含深证成指等）在其数据目录中存在。
- 缺失：S4 要求「条款必须清晰」——数据来源、API 授权、保存与再展示均无书面规定；按 ADR 0001 决策 5 与 ADR 0004 决策 5，在条款补齐或所有者书面接受风险前不得用于解锁真实模式。

### 2.6 东方财富 push2 接口（push2.eastmoney.com / push2his.eastmoney.com）

**提供方身份**：东方财富信息股份有限公司（东方财富网）。

**访问方式（实测）**：`https://48.push2.eastmoney.com/api/qt/clist/get?...&fs=i:1.000001,i:0.399001,i:0.399006&fields=f2,f3,f4,f12,f14` 无需 Referer / 登录即返回 JSON（含 CORS 头），一次请求可覆盖三个核心指数的点位与涨跌幅。技术上是三家里最顺的。

**条款**：法律声明 https://about.eastmoney.com/home/legal （首页页脚「法律声明」），关键原文：

> 十、特别声明　**未经深圳证券交易所和上海证券交易所等交易所的事先书面同意，任何机构或个人不得以任何理由和方式将本网站的行情信息进行复制、传播、转播、演示或任何其他形式的散发。**

> 八、版权　……未经东方财富或相关权利人事先书面许可，任何人不得将本网站上的任何内容以任何方式进行复制、修改、转载、传播、经销、翻印、演示、出版或任何其它形式的散发。

> 四、用户对本网站的使用　……您不得以任何方式（包括但不限于使用任何设备、软件或程序）干扰或试图干扰本网站的正常运作……您同意不会从事任何可能会对本网站及其相关的架构、系统、网络带来不合理或不成比例的高负载的行为。

**判定**：

| 维度 | 判定 | 依据 |
| --- | --- | --- |
| 保存响应 | 不允许 | 第十条把「复制行情信息」的上游许可明确锁在**交易所书面同意**上；保存 push2 原始响应即构成复制 |
| 再展示 | 不允许（散发类） | 同上，「传播、转播、演示」均列禁止 |
| 程序化访问 | 无授权条款 | 未禁止低频读取本身，但禁止高负载行为；对数据使用的限制已独立成立 |

**结论：不符合**。保存原始响应这一项直接触发 ADR 0004 决策 5 的否决条件；除非取得交易所书面同意（超出本项目预算与范围）。

### 2.7 新浪 hq.sinajs.cn

**提供方身份**：新浪公司（新浪财经）。

**访问方式（实测）**：
- 无 Referer 请求 → `HTTP 403 Forbidden`；
- 携带 `Referer: https://finance.sina.com.cn/` → HTTP 200，返回 GB18030 编码 JS 变量（实测 `s_sh000001` 含上证指数点位、涨跌点、涨跌幅）。

**公开说明情况**：该 Referer 限制**查无任何官方书面公告**（hq.sinajs.cn 无 robots.txt，返回 404；新浪财经站点与页脚无行情数据使用条款），限制仅以实际封锁行为存在，属不成文访问规则。

**条款**：新浪知识产权声明 http://corp.sina.com.cn/chn/copyright.html （新浪财经页脚「版权所有」指向的唯一法律页，文本落款 1996-2004，内容较旧但仍是现行站点声明）：

> 除非中国法律另有规定，**未经新浪公司书面许可**，对于新浪公司拥有版权和/或其他知识产权的任何内容，任何人不得**复制**或在非新浪公司所属的服务器上做镜像或以其他任何方式进行使用……

**判定**：

| 维度 | 判定 | 依据 |
| --- | --- | --- |
| 保存响应 | 条款不清晰（偏不允许） | 版权声明禁止未经书面许可复制其内容，未界定行情接口响应；接口无任何书面使用条件 |
| 再展示 | 条款不清晰 | 同上 |
| 程序化访问 | 限制为不成文规则 | 403 门禁客观存在但无成文授权 / 频次 / 用途规定；绕行方式（伪造 Referer）无授权依据 |

**结论：条款不清晰，按 S4 不得启用**。S3 要求「核验服务条款与访问规则」，而本候选的访问规则恰恰不成文——无法满足核验要求。

### 2.8 腾讯 qt.gtimg.cn / gu.qq.com

**提供方身份**：腾讯（腾讯网行情中心 / 腾讯自选股 Web）。

**访问方式（实测）**：`https://qt.gtimg.cn/q=s_sh000001,s_sz399001,s_sz399006` 无需 Referer / 登录即返回 GBK 编码报价（含三个核心指数点位与涨跌幅）。`qt.gtimg.cn/robots.txt` 返回 200 但内容仅为 "bad request" 文本（无有效规则）。

**访问规则核验**：行情站 `https://gu.qq.com/robots.txt`：

```
User-agent: *
Disallow: /
```

——对一切自动化抓取全站禁止。

**条款**：gu.qq.com 页脚「服务条款」指向 http://www.qq.com/contract.shtml （正文现由 https://www.qq.com/contract20180827.htm 提供；rule.tencent.com/rule/202504020001 为新版入口，内容为 JS 渲染），关键原文：

> 4.5 **任何人未经腾讯授权不得使用任何第三方软件、插件、外挂、系统等查看、获取本服务中所包含的**腾讯、腾讯合作伙伴或用户的任何相关信息、数据等内容，同时，应当严格遵守腾讯发布的Robots协议等相关协议规则。

> 10.4 除非腾讯书面许可，您不得从事下列任一行为：……（3）对腾讯拥有知识产权的内容进行使用、出租、出借、**复制**、修改、链接、转载、汇编、发表、出版、建立镜像站点等。

**判定**：

| 维度 | 判定 | 依据 |
| --- | --- | --- |
| 保存响应 | 不允许 | 10.4(3) 复制禁令，未经书面许可 |
| 再展示 | 不允许 | 同上（转载、汇编、出版） |
| 程序化访问 | 不允许 | 4.5 明文禁止未经授权以第三方程序获取数据；且 gu.qq.com robots 全站 Disallow |

**结论：不符合**。程序化访问与保存响应两项均被条款明文禁止。

## 三、推荐组合

**官方腿（对应交易所官方来源）**：

- 上证指数 000001.SH → 上交所官网行情走势页 / query.sse.com.cn 端点（2.1）
- 深证成指 399001.SZ、创业板指 399006.SZ → 深交所官网深市指数页 / szse.cn ShowReport 接口（2.2）

理由：这是全部候选中唯一在条款文本上落在允许侧的来源——两家交易所法律声明第三条第一句明确允许「基于非商业目的浏览、下载」，本项目恰好是本地、非商业、单维护者用途；零预算、免注册；端点实测公开可访问。启用前置条件（ADR 0001 决策 3 已有框架）：所有者批准对「存贮、电子抓取」措辞的解释（见开放问题 1）并完成来源登记；实施每日盘后一次级别的低频访问、原始响应保存、结构变化检测。

**独立 API 腿**：**当前没有候选通过**。

- Tushare：指数日线需 2000 分（免费路径不可达）+「仅可用作个人查看使用」（2.3）
- 东方财富：条款明文禁止复制行情信息（2.6）
- 新浪：复制禁令 + 接口限制不成文（2.7）
- 腾讯：4.5 禁止未经授权程序化获取 + robots 全禁（2.8）
- BaoStock：条款不清晰（2.4）

**因此在找到合规独立 API 前，按 ADR 0001 决策 5，真实模式保持禁用**——宁可推迟，不以单来源发布、许可推测或未登记抓取换取进度（ADR 0001 后果条款）。

## 四、仍需所有者拍板的开放问题

1. **交易所法律声明的解释风险**：上 / 深交所第三条把「存贮、电子抓取」列在「以向他人出售牟利为目的」的枚举里。按语法非商业保存不落入禁令，但这是解释而非交易所的明文许可。是否接受该解释并登记启用？是否需要向交易所（上证所信息网络有限公司）发函确认？发函会超出零预算与本地项目的时间尺度。
2. **独立 API 腿的路线选择**（三选一或维持现状）：
   - a. 维持真实模式禁用，继续用 mock / 黄金集推进其余工作，等出现合规免费来源；
   - b. 修订 ADR 0001 允许小额付费（如 Tushare 200 元 / 年），并要求 Tushare 方面确认保存响应的许可——这与现行 ADR 冲突，需走 ADR 变更流程；
   - c. 若所有者具备高校师生身份，用 Tushare 免费教育积分（2000 / 5000 分）——但「仅可用作个人查看使用」仍与黄金案例保存原始响应冲突，仍需来源方确认。
3. **BaoStock 风险偏好**：是否接受向阿尔法联合（上海）软件技术有限公司确认其数据 API 的授权条款（数据来源、能否保存响应、免费无 token 是否延续）？对方回复前，按 S4 只能维持「不得启用」。
4. **官方腿适配细节（若官方来源获批启用）**：query.sse.com.cn 的确切 sqlId / 参数与 szse.cn 指数 CATALOGID 需在适配器实现阶段确认；访问频率（建议每日盘后一次）、UA / Referer 规范、超时与失败处理需写入来源登记。
5. **条款失效监控**：以上条款均为 2026-10-05 快照（新浪版权声明甚至停留在 2004 版）。来源登记是否需要加入「条款页定期复查 + 哈希比对」以复用已有的结构变化检测机制？
